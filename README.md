# Tip Calculator
## Description
A simple C++ console program that calculates a tip percentage 
based off an initial price and displays the total after tip.
## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Enter price and percentage when prompted (must be >=0)
## Sample Input / Output
Input: Enter price: 100 Enter percentage: 20
Output: Tip amount: $20 Total after tip: $120
